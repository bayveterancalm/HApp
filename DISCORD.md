# Discord и HAPP

HAPP — имя этого репозитория и Windows-сборки Zapret/WinDivert. Включает стратегии запуска, служебные инструменты, IPSet и диагностику сетевого доступа к поддерживаемым ресурсам.

## Discord voice / RTC

В README этого репозитория описана диагностика бесконечного подключения к голосовому чату Discord. В качестве первых шагов рекомендуется проверить Discord в браузере, настроить Secure DNS, попробовать несколько стратегий и проверить актуальность hosts.

## Если Discord застрял на RTC Connecting

1. Проверьте https://discord.com/app.
2. Если браузерная версия работает, сравните её с настольным клиентом.
3. Проверьте Secure DNS.
4. Используйте `Update Hosts File`, если проблема относится к голосовому соединению.
5. Очистите кэш Discord и повторите проверку.

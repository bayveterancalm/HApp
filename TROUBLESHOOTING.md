# Диагностика HAPP

HAPP — имя этого репозитория и Windows-сборки Zapret/WinDivert. Включает стратегии запуска, служебные инструменты, IPSet и диагностику сетевого доступа к поддерживаемым ресурсам.

## Discord: бесконечное подключение к голосовому чату

1. Проверьте подключение к Discord Web: https://discord.com/app.
2. Настройте Secure DNS и повторите проверку.
3. Проверьте функцию `Update Hosts File` в `service.bat`; после ручного изменения убедитесь, что файл hosts сохранён.
4. Очистите кэш Discord и повторно протестируйте стратегии.
5. Если не помогает, зафиксируйте результат теста и обратитесь в [Discussions](https://github.com/Stuccozenupgrade/happ/discussions).

## YouTube: видео не запускается или долго загружается

- Проверьте Secure DNS.
- На время диагностики отключите расширения-блокировщики рекламы и сравните результат.
- Проверьте несколько стратегий по отдельности.
- Сравните работу в другом браузере.
- Не делайте вывод, что любой сбой YouTube вызван Zapret: возможны проблемы браузера, аккаунта, сети или самого сервиса.

## Telegram Web не подключается

- Проверьте Secure DNS.
- Используйте описанную в README функцию `Update Hosts File`.
- После применения убедитесь, что hosts сохранён с правами администратора.

## Telegram Desktop не подключается

README рекомендует отдельный [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy). Этот компонент не следует считать включённым в данный архив.

## Сайты перестали открываться после фильтрации

- Проверьте состояние `Game Filter` и `IPSet Filter`.
- Не оставляйте `IPSet any` включённым на постоянной основе: он может повлиять на доступность посторонних ресурсов.
- Верните настройки к предыдущему состоянию и проверяйте изменения по одному.

## WinDivert обнаруживается антивирусом

README предупреждает о возможной классификации WinDivert как RiskTool/PUA. Не добавляйте исключения, пока не проверили источник файла и контрольные суммы.

## Ошибка службы или драйвера

Проверьте права администратора, целостность файлов, поддержку версии Windows и сообщения Windows о драйверах. Для удаления служб используйте штатную функцию `Remove Services` из `service.bat`.

## Перед обращением за помощью

Приложите версию Windows, версию релиза, используемую стратегию, точный текст ошибки и список шагов воспроизведения. Не прикладывайте приватные данные и токены.

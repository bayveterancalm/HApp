# FAQ — HAPP

HAPP — имя этого репозитория и Windows-сборки Zapret/WinDivert. Включает стратегии запуска, служебные инструменты, IPSet и диагностику сетевого доступа к поддерживаемым ресурсам.

## 1. Что такое HAPP?

Это название данного репозитория и сборки для Windows. По README внутри архива пакет основан на Zapret/WinDivert и предназначен для настройки сетевых стратегий и диагностики.

## 2. Это официальный VPN-клиент HAPP?

Не следует считать этот архив отдельным VPN-клиентом или VPN-подпиской. README описывает Windows-сборку на базе Zapret/WinDivert.

## 3. Что именно скачивается?

В комплекте лежит архив Releases/happ.zip. Перед запуском проверьте содержимое и SHA256SUMS.txt.

## 4. Для какой Windows предназначен пакет?

README описывает использование в Windows. Отдельно упоминается Secure DNS Windows 11; проверяйте совместимость конкретной версии Windows и драйвера.

## 5. Подходит ли для Windows 10?

В описании пакета заявлена работа с Windows 10/11. Фактический результат зависит от конфигурации системы, драйверов и сети.

## 6. Подходит ли для Windows 11?

В README отдельно описана настройка Secure DNS в Windows 11. Это не гарантирует, что любая стратегия будет работать у каждого провайдера.

## 7. Что такое Zapret?

Zapret — набор инструментов и стратегий сетевой обработки трафика. В этом пакете используется Windows-компонент WinDivert.

## 8. Для чего нужен WinDivert?

WinDivert используется для перехвата и фильтрации сетевого трафика в Windows и нужен для работы включённой в пакет сборки.

## 9. Почему антивирус предупреждает о WinDivert?

README предупреждает, что некоторые антивирусы классифицируют WinDivert как RiskTool/PUA. Не отключайте защиту автоматически: сначала проверьте источник и контрольные суммы.

## 10. Как проверить файлы архива?

Сверьте файлы с SHA256SUMS.txt, скачивайте только из доверенного репозитория и проверяйте целостность архива.

## 11. Где скачать обновление?

Используйте Releases соответствующего репозитория. Не скачивайте случайные копии с неизвестных сайтов.

## 12. Как распаковать архив?

Скачайте happ.zip из Assets релиза, при необходимости снимите блокировку файла в свойствах Windows и распакуйте в путь без кириллицы и специальных символов, как указано в README.

## 13. Нужно ли запускать от администратора?

Операции, которые устанавливают или удаляют системные службы и драйвер WinDivert, требуют соответствующих прав. Следуйте точной инструкции README.

## 14. Для чего general.bat?

README описывает general.bat и варианты стратегий как ручной запуск для проверки разных стратегий.

## 15. Для чего service.bat?

README перечисляет функции управления службами, Game Filter, IPSet Filter, обновления IPSet/hosts, диагностики и тестирования.

## 16. Что делает Game Filter?

Он переключает режим обработки игрового трафика и других сервисов, использующих UDP/TCP на портах выше 1023. Изменение может влиять на доступность приложений.

## 17. Что такое IPSet Filter?

Это режим применения списка IP-адресов и подсетей из IPSet. README предупреждает, что режим any может влиять на доступность других сайтов.

## 18. Нужно ли включать Secure DNS?

README рекомендует настроить Secure DNS в браузере или Windows 11. Выбор DNS-поставщика зависит от доступности и настроек сети.

## 19. Как включить Secure DNS в Chrome?

Откройте настройки безопасности Chrome, найдите параметр безопасного DNS и выберите доступного поставщика. Названия разделов могут меняться в разных версиях браузера.

## 20. Как включить DNS over HTTPS в Firefox?

В настройках Firefox откройте параметры конфиденциальности и DNS over HTTPS, затем выберите поддерживаемого поставщика.

## 21. Что делать, если YouTube не открывается?

README предлагает проверить Secure DNS, временно отключить блокировщик рекламы для диагностики и проверить другие стратегии. Работа не гарантируется.

## 22. Почему YouTube тормозит?

Причина может быть в DNS, браузере, расширениях, провайдере или конкретной стратегии. Проверьте Secure DNS и сравните результат в другом браузере.

## 23. Гарантирует ли пакет ускорение YouTube?

Нет. Скорость зависит от сети, региона, провайдера, DNS, браузера и текущих ограничений.

## 24. Можно ли использовать пакет для Discord?

README отдельно описывает проблемы подключения к голосовому чату Discord и предлагает диагностические шаги.

## 25. Что делать при Discord RTC Connecting?

Проверьте Secure DNS, откройте Discord Web для сравнения, протестируйте доступные стратегии и проверьте актуальность hosts по README.

## 26. Что делать, если Discord работает в браузере, но не в приложении?

Сравните версии приложения и веб-клиента, очистите кэш Discord, затем повторите проверку после выбора рабочей стратегии.

## 27. Помогает ли пакет для Discord Voice?

README указывает на возможное исправление подключения к голосовому чату через обновление hosts и подбор стратегии. Результат зависит от сети.

## 28. Поддерживается ли Telegram Web?

README описывает обновление hosts file как способ диагностики/исправления проблем с Telegram Web.

## 29. Что делать, если Telegram Web не открывается?

Проверьте Secure DNS и воспользуйтесь пунктом Update Hosts File в service.bat, затем проверьте, сохранились ли предложенные изменения.

## 30. Поддерживает ли пакет Telegram Desktop напрямую?

README рекомендует отдельный проект tg-ws-proxy для Telegram Desktop. Не следует считать поддержку Desktop встроенной функцией данной сборки.

## 31. Где взять tg-ws-proxy?

README ссылается на https://github.com/Flowseal/tg-ws-proxy. Проверяйте инструкцию и совместимость самого проекта.

## 32. Что делает Update Hosts File?

Эта функция помогает обновить hosts для диагностики Telegram Web и голосового подключения Discord — это прямо указано в README.

## 33. Почему после обновления hosts ничего не изменилось?

Проверьте, что файл hosts действительно сохранён с правами администратора, затем очистите DNS-кэш или перезапустите приложение по рекомендациям Windows.

## 34. Почему стратегия работает у одного провайдера, но не у другого?

Сетевые ограничения и маршрутизация различаются. README предлагает тестировать разные стратегии; универсального варианта для всех сетей нет.

## 35. Что делать, если интернет перестал работать после включения фильтра?

Остановите используемую стратегию или верните предыдущее состояние фильтров через штатные средства пакета. Не оставляйте IPSet any включённым без необходимости.

## 36. Можно ли постоянно использовать IPSet any?

README предупреждает, что такой режим может мешать открытию многих сайтов и не рекомендует использовать его постоянно.

## 37. Что делать, если Windows блокирует запуск?

Не обходите предупреждение вслепую. Проверьте источник, подпись и контрольные суммы; изучите предупреждение WinDivert в README.

## 38. Совместим ли пакет с Windows 7?

README описывает отдельный сценарий для Windows 7, требующий соответствующих версий WinDivert.dll и WinDivert64.sys. Это ручная процедура для опытных пользователей.

## 39. Что такое IPSet?

Это список IP-адресов и сетей, используемый фильтрами. В пакете есть основные и исключающие списки.

## 40. Как обновить IPSet?

В README указана функция Update IPSet List в service.bat. Выполняйте её из доверенной копии пакета.

## 41. Как проверить, работает ли стратегия?

В README указана функция Run Tests и набор Standard tests по адресам из utils/targets.txt.

## 42. Что делать, если обновление не найдено?

Проверьте доступность GitHub, актуальность версии, настройки сети и используйте страницу Releases соответствующего репозитория.

## 43. Где сообщить об ошибке?

Используйте раздел Issues или Discussions соответствующего GitHub-репозитория и приложите описание системы, сети и шаги воспроизведения.

## 44. Чем отличаются HAPP и другие HAPP-репозитории?

Различаются названия и отдельные репозиторные метаданные. Перед установкой проверяйте README, релиз и содержимое конкретной версии.

## 45. Можно ли использовать файл на другом компьютере?

Это портативный набор файлов, но драйверы и системные службы настраиваются отдельно для каждой Windows-системы.

## 46. Нужен ли Python?

README не указывает Python как требование для описанного стандартного запуска. Следуйте зависимостям, включённым в архив.

## 47. Нужен ли отдельный proxy для Discord?

Пакет не описан как прокси-клиент. В README речь идёт о стратегиях Zapret и настройке hosts/Secure DNS.

## 48. Что означает версия 1.7.7?

Это значение из releasetag.txt текущего архива. Не путайте его с версиями upstream-компонентов, упомянутыми в примечаниях.

## 49. Где посмотреть изменения?

Сверяйте CHANGELOG.md, исходный README и сведения на странице Releases. Здесь не приписываются изменения, которых нет в исходных материалах.

## 50. Гарантирует ли пакет обход всех ограничений?

Нет. Работа зависит от сетевой конфигурации и меняющихся условий. Используйте диагностику и учитывайте предупреждения README.

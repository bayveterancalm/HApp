# Telegram и HAPP

HAPP — имя этого репозитория и Windows-сборки Zapret/WinDivert. Включает стратегии запуска, служебные инструменты, IPSet и диагностику сетевого доступа к поддерживаемым ресурсам.

## Telegram Web

README описывает функцию `Update Hosts File` в `service.bat` как способ устранения некоторых проблем с веб-версией Telegram. После применения проверьте, что hosts действительно сохранён.

## Telegram Desktop

Для Telegram Desktop README рекомендует отдельный проект [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy). Не утверждаем, что Desktop-прокси встроен в данный архив.

## Диагностика Telegram Web

1. Проверьте Secure DNS.
2. Проверьте Telegram Web в браузере.
3. Используйте `Update Hosts File` по инструкции README.
4. Убедитесь, что файл hosts сохранён с правами администратора.
5. Если ошибка сохраняется, приложите шаги воспроизведения в [Discussions](https://github.com/Stuccozenupgrade/happ/discussions).

# История и сведения о версии — HAPP

- Repository release tag из исходного `releasetag.txt`: **1.7.7**.
- Имя release asset из исходного архива: **happ.zip**.
- Основой Windows-сборки в README указан Zapret/WinDivert.
- README описывает ручной запуск стратегий, управление службами, Game Filter, IPSet Filter, обновление IPSet/hosts, диагностику и тестирование.

## Важное замечание о версиях

В исходном `opisanierelease.txt` присутствует upstream changelog Flowseal с диапазоном версий 1.10.0...1.10.1, тогда как `releasetag.txt` этого репозитория содержит 1.7.7. Эти номера относятся к разным уровням версионирования; они не объединяются здесь в одну версию.

## Перед обновлением
